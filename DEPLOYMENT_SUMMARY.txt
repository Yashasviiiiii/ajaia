================================================================================
                         TROUBLESHOOTING QUICK FIX
================================================================================

"Failed to fetch" error?
  → Check VITE_API_URL in Vercel is correct
  → Visit backend URL to verify it's running

"CORS error" in browser?
  → Update CORS_ORIGINS in Render to include Vercel URL
  → Wait for Render to redeploy

Build fails on Render?
  → Check build logs in Render dashboard
  → Verify Python 3.10+ is available

Build fails on Vercel?
  → Check build logs in Vercel dashboard
  → Verify VITE_API_URL is set in environment variables

For more help: See DEPLOYMENT_CHECKLIST.md troubleshooting matrix
